# Group Website Starter

Basic project structure for the group website.

## Pages
- `index.html` — Home
- `about.html` — About
- `contact.html` — Contact
- `app.html` — React App placeholder
- `login.html` — Sign In placeholder

## Shared files
- `css/style.css`
- `js/main.js`

## Suggested workflow
Each group member can work on a different page or use a separate Git branch.
